פקודות ליצירת צילומי מסך למדריך TrustGrade

מותאם ל־Moodle 4.5 עם תבנית Boost (Bootstrap 5).

כל פקודה מופעלת מתוך תיקיית docs:

cd /path/to/local/trustgrade/docs

פורמט:

node moodle_screenshot.js <בסיס_כתובת> <כתובת_דף> <קובץ_פלט.png> [בורר1] [בורר2] ...

בוררים (selectors) – אלמנטים שלוחצים עליהם לפני צילום המסך (לפי הסדר).

קורס: https://dev.moodle/course/view.php?id=63
מטלה: https://dev.moodle/mod/assign/view.php?id=356
קורס במצב עריכה (Boost): course/view.php?id=63&edit=1
